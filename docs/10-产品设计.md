# 这很三国｜产品设计

## 一、基本流程

游戏以“一季”（春夏秋冬）为一个回合。

每季开始时，玩家获得固定的基础行动力，并查看当前天下局势。

玩家可以消耗行动力执行各种行动。行动力不足时，本季无法继续进行对应操作。

玩家结束本季后，其他势力按照各自的策略执行行动，随后结算战争、资源、事件与人物状态，进入下一季。

其他势力的主要行动对玩家可见。

```text
季初
 ↓
查看局势
 ↓
玩家行动
 ↓
结束回合
 ↓
其他势力行动
 ↓
世界结算
 ↓
进入下一季
```

## 二、玩家势力

玩家选择一个主要势力开始游戏。

势力由君主统领，君主是该势力中的一名武将，玩家以君主的视角治理势力。

势力拥有：

* 所辖的战略点
* 人口
* 金钱
* 粮食
* 部队
* 武将
* 外交关系
* 民心

民心反映治下民众的向背，随内政、战争与外交的结果变化，并影响金钱与粮食的产量以及征兵效率。

不同势力在初始条件上存在差异。

差异应主要来自真实的系统优势与劣势，而不是通过固定剧情保证某个势力必然发展。

例如，一个势力可以因为地理、人才、资源与组织能力天然更强，但仍然可能被玩家或其他势力改变其历史走向。

### 初版开局

初版固定以刘备势力开局，时间为**建安十三年（208 年）秋**：曹操南征、刘琮投降、长坂坡之后，刘备退至江夏与刘琦会合，仅据江夏一城。此时曹操已尽取荆北与江陵，兵力远胜；东面孙权据江东；荆南四郡尚无人主。

开局是一段序章。序章不是另一套规则，玩家自始至终按正常规则操作，序章只是用剧情与教学把最初的几个回合串起来：

```text
三顾茅庐（剧情）
   ↓
博望坡之战（教学战）
   ↓
长坂与退往江夏（剧情）
   ↓
诸葛亮教刘备整饬内政（教学：界面、行动力、内政操作）
   ↓
玩家自由发展若干回合
   ↓
赤壁之战（事件触发）
   ↓
曹操退往北方
   ↓
自由行动开始
```

赤壁在本设计里是一场**由事件触发的战役**，而不是玩家可以自行选择发动的进攻；它同时也是序章的收尾。赤壁之后，天下不再有任何预先写死的剧情，走势完全由规则与玩家的行动决定。

需要说明一处与史实的偏离：史实中赤壁就发生在建安十三年冬，距开局只有一个季度，不足以让玩家先发展若干回合。因此赤壁事件会在开局之后若干季度才触发，时间上略晚于史实。这符合「历史是初始条件，不是剧本」的定位。

开局时关羽、张飞、赵云、诸葛亮等核心武将数值偏低而成长上限较高，具体数值与培养机制待培养系统设计后确定。

## 三、州与战略点

天下在地理上划分为若干州，每州之内分布若干战略点。

战略点是领土与进攻的基本单位，势力实际占有的是战略点，而不是整片州域。战略点不以行政级别为限，分为城市、关隘、野地等类型：新野是城，虎牢关是关隘，博望坡是野地。类型决定战略点的定位与所携带的属性，具体差异随迭代逐步细化。

州在初版是地理分组，用于地图展示与人才寻访范围（势力在某州有至少一个战略点即可在该州寻访）。州的归属由占据战略点的多寡决定：占据最多者为该州归属势力；若与他方并列，则原归属势力保持，不立即变为无归属。开局时青、并、幽归曹操；张鲁（汉中）、刘璋（益州）、士燮（交州）、马超与韩遂（凉州陇右）等势力尚未建模，其所据之地无归属。州归属带来的收益留待后续。

## 四、行动力

行动力是玩家每季最重要的通用行动资源。

不同操作消耗不同数量的行动力。

原则上：

> **影响越大的操作，应该消耗越多行动力。**

例如：

| 行动    | 典型定位 |
| ----- | ---- |
| 寻访人才  | 中等   |
| 人事调整  | 低成本  |
| 简单外交  | 中低成本 |
| 建设    | 中等   |
| 招兵    | 中等   |
| 大规模调动 | 中高   |
| 进攻    | 高    |

具体数值见《游戏机制》，随实际游戏测试调整。

行动力不采用固定“本回合只能行动两次”的模式，也不追求无限行动。

玩家每个季度拥有的是一笔需要分配的预算。行动力是核心平衡资源，内政与事件不会使它提高；是否存在其他提高途径，留待后续设计。

## 五、人才寻访

人才寻访是玩家低成本、高反馈的行动之一。

玩家消耗少量行动力进行寻访，系统根据当前州、天下局势与人才状态随机产生候选人物。

寻访不是单纯抽取数值，而是：

> **发现一个可能改变自己势力未来的人。**

候选人才的完整形态包含多种处境（愿意立即加入、需要进一步接触、对当前势力没有兴趣、已经属于其他势力、流浪或暂未效忠）；初版实现在野者被寻到后按性格与倾向判定是否入仕，未成者记入待招募、可再花行动力拜访争取，其余处境留待后续。当前规则见《游戏机制》。

势力对一州的控制程度决定能寻到什么人：进入该州即可寻访基础人物，成为该州的归属势力开放更高一层，占该州全部战略点则全部开放。越强的名将越靠后，扩张因而在寻访上得到回报，玩家也要在「进入即寻访」与「占领后再寻访」之间权衡。

未效忠与在野的武将会随着世界变化：某势力灭亡后，其武将可能转为流浪或投奔他处。人才系统因此与世界模拟相连。

## 六、武将

每个核心武将至少拥有：

* 武力
* 统率
* 智谋
* 年龄
* 当前忠诚
* 势力倾向
* 性格特征
* 当前所属势力
* 所统率的部队与兵力
* 士气
* 状态

此处的状态指武将的处境，例如在野、在仕、被俘、退场，而不是忠诚或健康。年龄目前只做记录，随年份增长，是否引入年老与退休机制留待后续决定。士气暂时挂在武将上，待部队细化后再决定归属。

四项能力各有分工：武力用于单挑，统率决定部队的规模与成长，智谋用于战斗谋划，内政用于征兵、征粮等经营行为。

武将之间的关系属于独立的关系系统，初版不做。

### 势力倾向

武将拥有隐藏的势力倾向，记为对各势力的偏好：0–100 的自然数，50 为中性。

例如：

```text
张辽

曹操：85
吕布：70
刘备：50
```

偏好不直接展示。它以「偏好 − 50」的百分点修正招揽的成功率：偏好 90 时 +40%，偏好 20 时 −30%。

它主要影响：

* 加入意愿（寻访与招揽的成功率）
* 招降难度
* 特定情况下的行为

偏好是感觉，忠诚是价值观，两者互不决定。

人物经历、待遇与势力变化都可以改变武将的实际状态。

### 核心原则

> **武将当前属于谁，不等于他天然属于谁。**

因此，同一个历史人物在不同游戏中可能进入完全不同的势力。

## 七、人事

人事处理势力内部武将的任免与待遇，是留住与调动武将的主要手段。

玩家可以进行：

* 任免武将的职位
* 调整武将的驻守位置与所属部队
* 用资源赏赐或安抚武将
* 处置被俘武将，包括招降、释放与处决

人事只影响武将已有的忠诚、士气与状态。

## 八、兵力与战斗

军队以部队为载体，由武将统率；征兵直接编入武将统率的部队，势力不存在脱离武将的兵力。势力的兵力是其各部队之和。部队会持续消耗粮食，维持军队本身就是一项长期负担（部队耗粮随迭代 8 引入）。

部队驻扎在战略点上：进攻与调动都从选定目标开始——在地图上点中战略点，再决定进攻它还是把部队调入。进攻时排定主将、副将与军师的编成（主将必选，至多三人），兵力合计、智谋取三人中最高、士气取主将，胜则一同进驻新占的战略点、败则各自退回。每个武将在征兵、征粮、调动与进攻中每回合至多行动一次。

兵力不是背景数字，而是战斗结果的重要组成部分。

每个武将有带兵上限；被寻访招募的武将自带少量部队，此后每季按统率补充兵员，统率越高，部队规模增长越快。

对垒时一方可以提出单挑：对方拒绝，其士气下降；应战则胜者士气上升、败者下降；若单挑致阵亡，幅度更大。单挑经由士气影响战斗胜负，具体数值待定。

一个强力武将率领少量部队，不应天然战胜一个普通武将率领的大量部队。

战斗结果综合考虑：

```text
武将能力
+
兵力
+
兵种
+
士气
+
地形
+
战前策略
+
特殊能力
+
随机因素
```

兵种是初版的一部分，但种类保持少量，差异集中在少数维度上，不做复杂的相克体系。

目标不是建立复杂的军事模拟，而是保证玩家能够理解：

> 为什么一个历史上弱于关羽的武将，在这一局能够击败关羽。

例如华雄可以因为兵力、地形、士气与战术等条件获得优势，从而击败关羽。

### 战斗形式

初版倾向于：

> **战前由玩家进行战略选择，战斗过程由系统自动结算。**

玩家不直接操作单位移动和攻击。

这样可以把游戏重心保持在战略层，而不是转变成 RTS 或动作游戏。

是否增加少量战中干预，留待第一版完成后根据体验决定。

## 九、内政

内政为军事扩张提供长期资源。

人口是粮食生产与兵源的共同基础：有了人口才能生产粮食，才能征兵。粮食既用于征兵，也用于供养已经在编的部队。人口的上限由势力拥有的地盘决定。

初版只保留少量有明确作用的建设：

* 增加粮食收入
* 增加金钱收入
* 增加人口

每一个建设项目都应有清晰的战略价值。

不追求大量建筑与科技树。

## 十、外交

外交的主要作用不是提供大量文字对话，而是改变战略关系。

玩家可以进行：

* 结盟
* 停战
* 提升关系
* 索取或给予资源
* 劝降
* 宣战

外交关系影响战争、贸易、人才流动与 AI 决策。

外交行动应该成为行动力的重要消耗项，因此玩家无法在同一个季度无限处理外交事务。

## 十一、事件

事件用于在规则系统内制造变化、体现三国人物与题材特色、增加游戏趣味；不承担连续剧情的主要职责。

事件分三类：

* 系统事件：蝗灾、粮荒、流民、丰收、城内骚乱等，改变已有的资源、民心、兵力等状态，迫使玩家调整计划。
* 人物事件：武将不满、要求职位、主动离开、桃园结义等，依据武将的属性与状态触发；可以借用典故作为表现，但结果允许与史实不同。
* 趣味事件：以人物反差、异常组合与轻量文本制造笑点，同样只是已有状态的一次有意义变化。

事件可以自动结算，也可以出现需要玩家做出选择的时刻。

一条边界：初版事件的效果只作用于已有的属性与状态，不因事件新增游戏的基础机制，使新增事件主要是内容扩展。具体的约束与执行方式见《技术设计》。

## 十二、胜负

初版需要明确的结束条件，让一局游戏能够自然结束。

胜利条件是消灭其他所有势力，独占天下。

一个势力在失去全部地盘，或麾下不再有任何武将时灭亡，玩家所在的势力灭亡即为失败。

君主不会先于势力覆灭而离场：守城失守时必定撤走，交战中不参与单挑。初版因此不处理势力继承与内部动荡。

初版不设游戏内的时间上限，一局会一直进行到出现结果为止。

## 十三、多周目

多周目属于核心玩法验证后的扩展机制。

第一周目主要承担“学习规则”。

之后的周目可以通过奖励让玩家重新开始时有所不同。

周目奖励的类型可以很丰富：

* 信息揭示
* 新的便利
* 新的规则
* 新的开局选择

例如：

```text
一周目
隐藏部分信息

二周目
显示此前隐藏的信息

三周目
解锁特殊开局

后续
解锁特殊规则
```

这里只确定设计方向，不固定具体奖励方案。

## 十四、视觉与交互

游戏采用轻量的 2D 战略界面。

操作遵循「先选对象，再定行动」：在地图上点中战略点或部队，再决定对它做什么，而不是先选行动再去寻找目标。

重点表现：

* 天下地图
* 州与战略点
* 势力颜色
* 武将头像
* 资源变化
* 战报
* 事件
* 数值反馈

视觉方向倾向于具有中国古典和桌游感的原创设计，而不是直接模仿现有三国游戏。

第一版应优先保证玩法成立，美术资源可以逐步替换和精修。
