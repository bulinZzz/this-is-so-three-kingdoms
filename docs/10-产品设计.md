# 这很三国｜产品设计

## 一、基本流程

游戏以“一个月”为一个回合。

每个月开始时，玩家获得固定的基础行动力，并查看当前天下局势。

玩家可以消耗行动力执行各种行动。行动力不足时，本月无法继续进行对应操作。

玩家结束本月后，其他势力按照各自的策略执行行动，随后结算战争、资源、事件与人物状态，进入下个月。

其他势力的主要行动对玩家可见。

```text
月初
 ↓
查看局势
 ↓
玩家行动
 ↓
结束回合
 ↓
其他势力行动
 ↓
世界结算
 ↓
进入下月
```

## 二、玩家势力

玩家选择一个主要势力开始游戏。

势力由君主统领，君主是该势力中的一名武将，玩家以君主的视角治理势力。

势力拥有：

* 所辖的郡
* 人口
* 金钱
* 粮食
* 部队
* 武将
* 外交关系
* 民心

民心反映治下民众的向背，随内政、战争与外交的结果变化，并影响金钱与粮食的产量以及征兵效率。

不同势力在初始条件上存在差异。

差异应主要来自真实的系统优势与劣势，而不是通过固定剧情保证某个势力必然发展。

例如，一个势力可以因为地理、人才、资源与组织能力天然更强，但仍然可能被玩家或其他势力改变其历史走向。

## 三、州郡与归属

天下在地理上划分为若干州，每州下辖若干郡。

郡是领土与进攻的基本单位，势力实际占有的是郡。

州在初版是地理分组，用于地图展示与人才寻访范围（势力在某州有至少一个郡即可在该州寻访）。州的归属逻辑（占郡最多者取得、并列无归属、州归属收益等）属于核心玩法验证后的内容。

## 四、行动力

行动力是玩家每月最重要的通用行动资源。

不同操作消耗不同数量的行动力。

原则上：

> **影响越大的操作，应该消耗越多行动力。**

例如：

| 行动    | 典型定位 |
| ----- | ---- |
| 寻访人才  | 低成本  |
| 人事调整  | 低成本  |
| 简单外交  | 中低成本 |
| 建设    | 中等   |
| 招兵    | 中等   |
| 大规模调动 | 中高   |
| 进攻    | 高    |

具体数值通过实际游戏测试调整。

行动力不采用固定“本回合只能行动两次”的模式，也不追求无限行动。

玩家每个月拥有的是一笔需要分配的预算。行动力是核心平衡资源，内政与事件不会使它提高；是否存在其他提高途径，留待后续设计。

## 五、人才寻访

人才寻访是玩家低成本、高反馈的行动之一。

玩家消耗少量行动力进行寻访，系统根据当前州、天下局势与人才状态随机产生候选人物。

寻访不是单纯抽取数值，而是：

> **发现一个可能改变自己势力未来的人。**

候选人才可以处于不同状态：

* 愿意立即加入
* 需要进一步接触
* 对当前势力没有兴趣
* 已经属于其他势力
* 流浪或暂未效忠

未效忠与在野的武将会随着世界变化：某势力灭亡后，其武将可能转为流浪或投奔他处。人才系统因此与世界模拟相连。

## 六、武将

每个核心武将至少拥有：

* 武力
* 统率
* 智谋
* 年龄
* 当前忠诚
* 声望
* 野心
* 势力倾向
* 性格特征
* 当前所属势力
* 所统率的部队与兵力
* 士气
* 状态

此处的状态指武将的处境，例如在野、在仕、被俘、退场，而不是忠诚或健康。年龄目前只做记录，是否引入年老与退休机制留待后续决定。士气暂时挂在武将上，待部队细化后再决定归属。

声望是个人在天下间的名望。野心暂时只是一个数值字段，具体使用场景（如君主继位后的处置）待核心玩法验证后确定；野心家系统留待后续设计。

武将之间的关系属于独立的关系系统，初版不做。

### 势力倾向

武将拥有隐藏的势力倾向。

例如：

```text
张辽

曹操阵营：强倾向
吕布阵营：一定倾向
刘备阵营：中性
其他势力：中性或较低
```

具体数值不直接展示。

它主要影响：

* 加入意愿
* 初始忠诚
* 招降难度
* 长期留任
* 特定情况下的行为

这个属性不是“固定忠诚”。

人物经历、待遇与势力变化都可以改变武将的实际状态。

### 核心原则

> **武将当前属于谁，不等于他天然属于谁。**

因此，同一个历史人物在不同游戏中可能进入完全不同的势力。

## 七、人事

人事处理势力内部武将的任免与待遇，是留住与调动武将的主要手段。

玩家可以进行：

* 任免武将的职位
* 调整武将的驻守位置与所属部队
* 用资源赏赐或安抚武将
* 处置被俘武将，包括招降、释放与处决

人事只影响武将已有的忠诚、士气与状态。

## 八、兵力与战斗

军队以部队为载体，由武将统率；征兵直接编入武将统率的部队，势力不存在脱离武将的兵力。势力的兵力是其各部队之和。部队会持续消耗粮食，维持军队本身就是一项长期负担。

兵力不是背景数字，而是战斗结果的重要组成部分。

一个强力武将率领少量部队，不应天然战胜一个普通武将率领的大量部队。

战斗结果综合考虑：

```text
武将能力
+
兵力
+
兵种
+
士气
+
地形
+
战前策略
+
特殊能力
+
随机因素
```

兵种是初版的一部分，但种类保持少量，差异集中在少数维度上，不做复杂的相克体系。

目标不是建立复杂的军事模拟，而是保证玩家能够理解：

> 为什么一个历史上弱于关羽的武将，在这一局能够击败关羽。

例如华雄可以因为兵力、地形、士气与战术等条件获得优势，从而击败关羽。

### 战斗形式

初版倾向于：

> **战前由玩家进行战略选择，战斗过程由系统自动结算。**

玩家不直接操作单位移动和攻击。

这样可以把游戏重心保持在战略层，而不是转变成 RTS 或动作游戏。

是否增加少量战中干预，留待第一版完成后根据体验决定。

## 九、内政

内政为军事扩张提供长期资源。

人口是粮食生产与兵源的共同基础：有了人口才能生产粮食，才能征兵。粮食既用于征兵，也用于供养已经在编的部队。人口的上限由势力拥有的地盘决定。

初版只保留少量有明确作用的建设：

* 增加粮食收入
* 增加金钱收入
* 增加人口

每一个建设项目都应有清晰的战略价值。

不追求大量建筑与科技树。

## 十、外交

外交的主要作用不是提供大量文字对话，而是改变战略关系。

玩家可以进行：

* 结盟
* 停战
* 提升关系
* 索取或给予资源
* 劝降
* 宣战

外交关系影响战争、贸易、人才流动与 AI 决策。君主的声望会影响其他势力对玩家的态度，也会影响招降与人才来投的难易。

外交行动应该成为行动力的重要消耗项，因此玩家无法在同一个月无限处理外交事务。

## 十一、事件

事件用于在规则系统中制造变化、体现三国人物与题材特色，以及增加游戏趣味。

事件不承担连续剧情的主要职责。

### 事件设计原则

**初版事件的效果只能作用于已有的属性与状态，不得因为事件而新增游戏的基础机制。**

事件可以自动结算，也可以出现需要玩家做出选择的时刻；两种形式的结果都只是已有属性与状态的变化。

例如：

```text
桃园结义
→ 三名武将忠诚提升
```

而不是：

```text
桃园结义
→ 新增“结义”关系类型
→ 新增结义专属战斗规则
→ 新增特殊行动
```

这样可以在不扩大底层规则的情况下，大量增加趣味事件。

事件应当足够轻量，使新增事件主要表现为：

> **已有系统状态的一次有意义变化。**

事件本身不应该因为“历史上发生过”就要求完整复刻原剧情。

### 系统事件

例如：

* 蝗灾
* 粮荒
* 流民
* 丰收
* 郡内骚乱

作用是改变已有资源、民心、兵力等状态，迫使玩家调整计划。

### 人物事件

少量根据武将属性与状态触发的事件。

例如：

* 武将不满
* 武将要求职位
* 武将主动离开
* 桃园结义
* 三顾茅庐

人物事件可以借用三国人物与典故作为表现，但最终效果仍优先落在已有属性上。

例如“桃园结义”可以根据当前武将状态选择结义对象，从而产生不同结果。正常情况下可能得到刘备、关羽、张飞，但也允许出现刘备、诸葛亮、周瑜等非历史组合。

### 趣味事件

通过人物反差、原创梗、异常组合和轻量文本制造笑点。

趣味事件同样是已有状态的一次变化，只是取材与表现更为荒诞；它增加游戏个性，但不承担核心玩法。

### 后续演进

如果某类事件经过实际游玩验证后很有价值，可以进一步扩展为具有持续效果或专属机制的高级事件。

因此事件的演进路径可以是：

```text
轻量事件
 ↓
属性变化
 ↓
玩家验证是否有趣
 ↓
值得深化
 ↓
持续效果 / 专属机制
```

初版不提前为事件建立大量专用机制。

## 十二、胜负

初版需要明确的结束条件，让一局游戏能够自然结束。

胜利条件是消灭其他所有势力，独占天下。

一个势力在失去全部地盘，或麾下不再有任何武将时灭亡，玩家所在的势力灭亡即为失败。

君主阵亡后，需要完成势力继承与内部动荡的处理。具体规则（继位者选择方式、野心处置等）待核心玩法验证后确定。

初版不设游戏内的时间上限，一局会一直进行到出现结果为止。

## 十三、多周目

多周目属于核心玩法验证后的扩展机制。

第一周目主要承担“学习规则”。

之后的周目可以通过奖励让玩家重新开始时有所不同。

周目奖励的类型可以很丰富：

* 信息揭示
* 新的便利
* 新的规则
* 新的开局选择

例如：

```text
一周目
隐藏部分信息

二周目
显示此前隐藏的信息

三周目
解锁特殊开局

后续
解锁特殊规则
```

这里只确定设计方向，不固定具体奖励方案。

## 十四、视觉与交互

游戏采用轻量的 2D 战略界面。

重点表现：

* 天下地图
* 州郡
* 势力颜色
* 武将头像
* 资源变化
* 战报
* 事件
* 数值反馈

视觉方向倾向于具有中国古典和桌游感的原创设计，而不是直接模仿现有三国游戏。

第一版应优先保证玩法成立，美术资源可以逐步替换和精修。
