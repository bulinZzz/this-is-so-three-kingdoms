# 地点信息

本文是「建安十三年」的讨论用攻略，逐点记下归属、驻将与邻接，供议版图时对照。它不是游戏数据的依据：数值以游戏内为准，版图改动后本文未必同步，动手改数据前请再核对。

读法：

* 类型分都会、大城、小城、关隘、野地。全图每一处战略点都有归属，不存在无主战略点。
* 野地人口恒为零，没有防守补正，不可建设，可驻一名武将。
* 人口上限按类型定档：都会二十万、大城十五万、小城十万、关隘四万；建民居每级再加一万，表中所列为未建民居时的基准。野地没有人口上限，表中记「—」。
* 类型与人口分开配置，同为小城也可人口繁多；人口上限只由类型决定。
* 每处战略点至多一名驻将。有主而无驻将的点，他方守备从活动范围含此城的在册武将中选派有兵而未行动的；玩家麾下不受活动范围限制。
* 邻接只列直通地点，行军须逐点经过。

两州眼下没有战略点，也不归任何势力；青州在徐州之北，并州在冀州之西，都是留白。

## 可议事项

* 江夏只接赤壁与柴桑，是长江中游的断头点；要不要补江陵—江夏，或江夏—襄阳？
* 陈留—邺—蓟—右北平—柳城—襄平、成都—泸水—秃龙洞—三江城—桃花渡、桂阳—番禺—广信—合浦—龙编/九真三条通路都是单链，断一处即断一片；哪些地方值得补旁路？
* 曹操二十二处据点里十处无驻将，洛阳、蓟、寿春、下邳等后方与二线都靠名册临时抽调；是否需要在几处常设驻将？
* 八处野地不产兵粮、没有防守补正，却计入势力存亡；子午谷、街亭、祁山、定军山、赤壁五处空置，是否值得派将？
* 青州、并州没有点，北方纵深全在曹操与公孙康手里；要补点，还是保持留白？
