# 武将信息

本文按势力列出「建安十三年」的武将名册、驻守、兵力与能力，供查阅人物与调整数值时对照。

读法：

* 武将归入所属势力的名册，驻守只是名册内的一项指派。
* 每处战略点至多一名驻将。「驻守」列写驻守点名称，未驻守写「-」。
* 兵为开局兵力，不是上限；每位武将的兵力不超过统率 ×150。
* 兵种分步兵、弓兵、骑兵，随人而定，征兵只补充数量，不改兵种。军师、都督、谋士一类坐镇后方的角色统一作弓兵。
* 武、统、智、政依次记武力、统率、智谋、内政，写作「武/统/智/政」。
* 忠为忠诚；备注只记年龄、性格、君主、关键好感与特殊身份，同势力好感从略。
* 名册三十人的上限只约束玩家势力；他方势力不设上限，人数随领地与战事增长。
* 「活动范围」列即其城池清单；在野时以首位所在州为招募州。它只约束他方势力：他方的驻守、征兵、征粮、赈济、建设、防守与出兵按清单取人，敌将的出现因此有迹可循；玩家麾下不受此限。攻下之地并入参战者的清单。
* 清单内已无本方城池时，他方武将仍可出场；每季初随机取一处本方城池为当季活动点，整季固定。
* 各势力表中自上而下的次序即「名册次序」，他方编成按此取人。
* 在野者按招募州（地点列表首位）与卡池层级另列于文末。

## 名册与兵力概览

名册的厚薄按「能不能同时打两仗」定下限。一季十点行动力至多支撑两次进攻，每次从名册里选一至五人，故一个势力至少要凑出两套互不重复的出征人马。刘备开局只有六人，刚好凑一队，第二队得靠寻访与征兵慢慢补——这是玩家前期的成长线；荆南十二人可以打两仗，却要分守四郡；大势力则厚在驻守与轮换上。

名册三十人的上限只约束玩家。玩家往后每收一人，都要在三十个格子里做取舍；他方势力不设此限，曹操据二十二处据点、二十六个在仕，仍会继续寻访收纳——地盘越大，人越多。

兵力逐层拉开。曹操二十六人十九万，孙权二十五人八万七千五百，两家单将的平均兵力相差一倍有余；马腾四万五千五百，约为孙权的一半，却明显高于汉中、辽东、交州三家。同一层内，据点多的未必兵多——南蛮十二人两万七千，兵均摊在四名头领身上，久战乏力；刘璋二十人两万八千，人数多而单将薄，守点够用，野战不足。

忠诚低的人集中在几处：荆南黄忠、魏延，刘璋法正、张松、孟达，汉中的杨松，南蛮的杨锋，西凉联军的韩遂。他们既是势力覆灭时的隐患，也是玩家赏赐、笼络的对象。

在野池按州分三层。三级只放四州：荆州庞统、司隶司马懿、幽州田畴、凉州杨阜——这四州没有一家能全控，三级是留给「把势力伸进来」的人。豫州、兖州、冀州、徐州全在曹操手中，若设三级，曹操开局即可自取，故只留基础与二级。青州、并州没有战略点，不设人才池。

## 活动范围

每名武将的城池清单见各势力表。他方的驻守、征兵、征粮、赈济、建设、防守只能在本方所有、且列在清单上的城池；出兵须从这样的城池出发，目标与之相邻。玩家麾下不受此限，可在本方任一据点驻守、征兵、征粮、赈济、建设、防守，并可对与本方据点相邻的目标出征。攻下一地后，该地并入此战参战武将的清单。

在野者的招募州按清单首位所在州计，列表跨州时也只看首位。清单内已无本方城池时，他方武将每季初由全局随机数在本方城池中取一处作为当季活动点，整季固定。

活动范围让每处战场只用本地的人马。曹操的襄阳、合肥、长安各有各的守将，前线的名将不会被抽调到别处，也不会因为打了几仗就整州无人可用——战事越往腹地，越难打。玩家麾下不受此限，名册中任何可用武将都可派往任一战场。
