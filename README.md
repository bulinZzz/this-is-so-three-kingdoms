# 这很三国

一个运行于浏览器的轻量三国战略游戏。建安十三年秋，刘备退守公安与江夏；此后历史不再预设，天下走势由规则与你的决策决定。

**当前版本：1.0.0**（2026-11-01），更新内容与已知问题见 [CHANGELOG](CHANGELOG.md)。

## 1.0 包含什么

1.0 是首个可玩版本，核心玩法循环已经成立：一局从开局出发，经前期探索、中期经营与扩张，走到胜负结算。

- 十家势力、六十七处战略点、一百三十三名在仕武将、五十名在野武将
- 季度回合与行动力预算
- 地图、势力关系与逐点行军
- 人才寻访、人事、内政、外交与俘虏
- 逐次手操战斗：布阵、行动条、攻击与守卫、战报
- 胜负结算与本地自动存档

主要体验集中在前期探索与中期经营、扩张。中后期的战略差异化与长期耐玩性尚待完善：正式剧本的固定种子推演能在 160 季内打灭荆南、士燮、刘璋与南蛮，但打不到全图统一。全图统一不作为 1.0 的发布验收条件，1.0 也不把这段尚未验证的长期战役体验描述为已完成能力。

1.0 不含正式事件内容体系：事件管线与词表已备，实际进入游戏的只有一条临时事件「南郡风云」，用于临时打通西川方向，后续事件系统落地时重做。武将特技与兵种相克、正式立绘、更强的他方 AI、地图与界面的统一重做、移动端适配同样排在 1.0 之后，见 [迭代计划](docs/90-迭代计划.md)。

## 本地启动

需要 Node.js 20.19 以上。

```bash
npm install
npm run dev
```

终端会输出访问地址，在浏览器中打开该地址即可（默认是 <http://localhost:5173/this-is-so-three-kingdoms/>）。

主要面向桌面浏览器，建议使用近两年的 Chrome、Edge、Firefox 或 Safari。

## 操作要点

- 标题页「开始游戏」以正式剧本重开，「读取进度」打开存档列表。
- 点击地图上的战略点，在右侧面板查看归属、驻将与可执行的动作。
- 每季有 10 点行动力，未用完不累积；结束本季后他方依次行动。
- 进度在每回合开始时自动保存，本回合内的操作不落盘；手动槽位不受影响。
- 战斗窗口不设关闭按钮，退出走「放弃战斗」。

## 其他命令

```bash
npm run build       # 类型检查并构建到 dist/
npm run preview     # 预览构建结果
npm test            # 运行规则层测试
npm run acceptance  # 无画面推演：按固定种子跑完整局，输出逐季日志与汇总，供调数值后复跑对照
```
